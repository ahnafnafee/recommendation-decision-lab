# Code of conduct

This repository has one maintainer, and the rules are short.

## What to do

- State the problem, then the number. A report that names the command, the
  Python version and the machine can be answered; the same words without them
  cannot.
- Read CONTRIBUTING.md before a pull request. The committed numbers depend on
  the exact split, the exact seed and the release check, so a change that
  moves any of those needs a sentence saying which one and why.
- Disagree with a number by reproducing it, not by restating it.

## What happens to a report

A maintainer replies, or closes the report with a reason. If a contribution
cannot be kept, the reason goes in the closing comment.

The MIT license covers the code and the documents; it does not cover tone.
Be direct, name the file and the line when you can, and keep the argument on
the code rather than the person.
