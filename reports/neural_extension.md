# A neural challenger that did not earn the route

Ahnaf An Nafee · 22 September 2026

The original system compares recent popularity with a co-review hybrid. This extension asks whether a learned retrieval representation adds enough quality to replace that active route. The model has a history tower and an item tower, trained with in-batch softmax on 313,522 chronological pairs from the Musical Instruments training split. Duplicate targets and items already present in a query history are masked as negatives. The fixed model has 64-dimensional embeddings, a 20-item history window, three training epochs and a 0.15 contrastive temperature. Fitted weights remain local. The architecture follows established dual-encoder retrieval practice, rather than proposing a new neural method; see [Google's account of candidate generation](https://research.google/pubs/deep-neural-networks-for-youtube-recommendations/) and the [cross-batch negative sampling paper](https://arxiv.org/abs/2110.15154) for context.

The unblended model scored 0.001411 NDCG@10 on validation, far below recent popularity's 0.010715. A validation-selected blend with 40% neural score reached 0.011774, but the existing co-review hybrid reached 0.011969. The paired user-cluster interval for neural minus hybrid was −0.000195 [−0.000985, 0.000611], so the stronger-challenger gate stayed closed. On the previously studied test period, the same blend scored 0.008357 against 0.008007 for recent popularity and 0.008681 for the co-review hybrid. The active route therefore remained the hybrid. [Aggregate results](neural_musical_exploratory.json) include counts, source hashes, intervals and timing scope.

This is an exploratory extension. The category's test period had already been used by the earlier study before this model was designed, so its result is not an independent confirmation. The public 5-core subset also has retrospective support filtering, and reviews are neither exposure logs nor an online utility measure. The model provides a reproducible deep-learning training path, exact full-catalog evaluation, calibrated comparison and a local shadow-serving path. Its main finding is a routing decision: extra model capacity did not justify replacing the simpler hybrid on this evidence.
